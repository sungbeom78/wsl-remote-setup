# ADR 0006 — 쉬운 화면 문구와 단계별 작업 기록

- 상태: 채택 (사용자 피드백, 2026-10-18)

## 맥락

`autostart plan/install` 화면에 기술 값이 그대로 나왔다. 설치 ID(GUID), 계정 SID, SHA-256, 서버 키 지문, 파이프 이름, 명령줄 등이다. 사용자는 이런 값이 오히려 화면을 복잡하게 만든다고 했다.

사용자가 요청한 것은 세 가지다.
- 컴퓨터를 잘 모르는 사람도 이해할 수 있는 말로 표시한다.
- 기술 값은 결과 기록 파일에만 남긴다.
- 기록은 작업이 끝난 뒤가 아니라 **단계마다 진행하면서** 남겨 히스토리로 쓸 수 있게 한다.

## 결정

1. **화면**에는 쉬운 말만 쓴다. 용어는 다음처럼 바꾼다.

   | 기술 용어 | 화면 표현 |
   |---|---|
   | portproxy | 연결 전달 규칙(외부 1004번 → WSL SSH) |
   | 방화벽 규칙(원격 CIDR, Private) | 방화벽 허용 규칙: 같은 공유기에 연결된 기기(192.168.1.0~255)만, '개인 네트워크'일 때만 |
   | Windows 서비스(LocalSystem) | 백그라운드 연결 관리 프로그램(컴퓨터가 켜지면 자동 시작) |
   | 로그온 작업(InteractiveToken, LeastPrivilege) | 로그인하면 자동 실행(관리자 권한 없이, 비밀번호 저장 안 함) |
   | host key 지문 | WSL SSH 서버 확인: 처음 설치 때 등록한 서버와 같음/다름 |
   | 설치 ID, SID, SHA-256, 파이프 이름 | 표시하지 않음(기록 파일에만 남김) |
   | 차단 사유 [BLOCK] | "진행할 수 없음: …"(무엇을 하면 되는지 함께 안내) |

2. **작업 기록**(`OperationHistory`)
   - 단계마다 `시작 → 세부값 → 완료/실패/변경 없음`을 **즉시** 파일에 덧붙이고 flush한다. 중간에 멈춰도 어디까지 진행했는지 남는다.
   - 기록 위치
     - 관리자 작업: `C:\ProgramData\WslRemoteSetup\logs\history.log` (보호 경로)
     - 일반 작업(plan, doctor): `%LOCALAPPDATA%\WslRemoteSetup\logs\history.log`
   - 화면 끝에 "자세한 진행 기록: <경로>"를 표시한다.
   - 비밀번호·개인키는 기록하지 않는다. SID·내부 IP는 기록에 남으므로, 기록을 공유하기 전에 확인이 필요하다.
3. **사용자가 입력하던 기술 값을 줄인다.**
   - 설치 ID와 서버 키 지문은 기록(상태 파일, WSL 안의 SSH 설치 기록, 보호 정책)에서 읽는다.
   - 그래서 `forward plan`과 `autostart plan|install|remove`는 인수 없이 실행할 수 있다.
   - `forward apply`는 관리자 창에서 WSL을 실행하지 않기 때문에, `forward plan`이 알려 준 `--wsl-ip` 하나만 받는다.

## 제한

- 진단 JSON(`doctor --json`)은 기술 자료이므로 기존 형식을 유지한다.
- 로그온 작업의 실행 인수에는 설치 ID가 들어간다. 이 값은 작업 스케줄러 내부 값이며 사용자 화면에는 나오지 않는다.
