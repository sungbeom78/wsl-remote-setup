# ADR 0001 — G2 WSL 배포판 소유 Windows 계정

- 상태: **승인됨** (2026-10-17, 사용자 채팅 확정)
- 날짜: 2026-10-17

## 맥락

WSL 배포판은 Windows 계정별로 등록된다. G2 실측 결과 사용 가능한 계정은 다음과 같다.

| 후보 | 근거 | 단점 |
|---|---|---|
| **ownerAdmin** (SID …-1002) | 실제로 원격(RDP 7389)에 사용 중인 계정. Remote Desktop Users 구성원. 현재 Claude 작업 세션의 계정이라 소유자 세션에서 Ubuntu 초기화·개발을 바로 진행 가능 | Administrators 구성원(일반 세션은 필터링 토큰이므로 WSL 실행 자체는 비승격) |
| consoleuser (MS 계정, …-1001) | 콘솔 소유자 | 원격 사용 이력 없음, 현재 Disconnected, Microsoft 계정 |
| 신규 remoteControl | 제품 기본값, 일반 사용자 | 불필요한 계정 추가. 기존 원격 계정이 있으면 재사용 원칙에 어긋남 |

## 결정(제안)

G2 개발 환경의 Ubuntu-24.04 소유자는 **ownerAdmin (S-1-5-21-1000000001-2000000002-3000000003-1002)** 으로 한다.

- 신규 계정을 만들지 않는다. 기존 그룹 구성은 변경하지 않는다.
- 배포판 등록은 ownerAdmin의 **비승격** 세션에서 수행한다(승격 콘솔·다른 계정에서 등록 금지).

## 제한·후속

- 소유자가 관리자 그룹 구성원이므로, M3의 "일반 사용자 소유자 + 관리자 설정 계정"(T09) 권한 분리 POC는 G2 기본 소유자로는 입증되지 않는다. M3에서 별도 일반 테스트 계정을 승인받아 만들거나 NOT_TESTED로 남긴다.
- consoleuser 계정에 이후 다른 배포판이 생겨도 이 도구의 관리 대상이 아니다.
