# ADR 0007 — DHCP 주소 변경 따라가기(선택)

- 상태: 채택 (사용자 승인 2026-10-18). 코드·단위 테스트 완료, 실기 NOT_TESTED(G2는 고정 주소)

## 맥락

연결 전달 규칙과 방화벽 규칙은 이 PC의 특정 주소(예: 192.168.1.222)에 묶여 있다. PC가 DHCP를 쓰면 주소가 바뀔 수 있고, 바뀌면 외부 접속이 끊긴다.

개발 계획 FR-05에는 "네트워크가 바뀌어 기존 수신 IP가 사라져도 다른 어댑터나 전체 인터페이스로 자동 확대하지 않는다"는 원칙이 있다.

## 결정

DHCP로 감지된 경우에만 `autostart install`(관리자 창)에서 묻는다. 기본값은 Y다.

> 이 PC 주소가 바뀌면 같은 공유기 범위 안에서 새 주소로 옮길까요?

허용하면 정책 파일에 다음 값을 기록한다.
- `followAddressChange = true`
- 수신 네트워크 카드 ID(`listenInterfaceId`)
- 승인 당시 LAN 범위(`lanCidr`)

백그라운드 연결 관리 프로그램은 다음 시점에 판단한다.
- 시작할 때
- 주소가 바뀌었다는 알림을 받았을 때
- 60초마다

**옮기는 조건** — 다음을 모두 만족할 때만 옮긴다.
1. 승인된 접속 주소가 이 PC의 어느 네트워크에도 없다.
2. 기록된 **같은 네트워크 카드**가 연결되어 있다.
3. 그 카드가 **개인 네트워크**(Private)다.
4. 그 카드에 **승인 당시 LAN 범위 안의 IPv4가 정확히 하나** 있다(link-local 제외).

**옮기는 방법**
- 이 도구가 만든 연결 전달 규칙을 새 주소로 다시 만든다. 대상(WSL)과 포트는 그대로 둔다.
- 이 도구가 만든 방화벽 규칙의 로컬 주소만 새 주소로 바꾼다. 원격 범위(LAN)와 프로필은 그대로 둔다.
- 정책·상태 파일의 접속 주소를 갱신하고, 작업 기록에 "주소 이동: 이전 → 새"를 남긴다.

**옮기지 않는 경우** — 아래 경우에는 Hold로 두고, `status`에 "주소가 바뀜"으로 알린다.
- 다른 네트워크 카드다.
- LAN 범위가 다르다(다른 공유기에 연결됨).
- 공용 네트워크다.
- 범위 안 주소가 여러 개다.
- 따라가기 설정이 꺼져 있다.

## FR-05와의 관계

이 기능은 **같은 카드·같은 LAN 범위·같은 Private 프로필** 안에서 한 주소를 다른 한 주소로 옮기는 것이다. 다른 어댑터, 전체 인터페이스(0.0.0.0), 더 넓은 원격 범위로 넓히는 일은 하지 않으므로 FR-05의 "확대 금지"를 지킨다.

## 제한

- 접속하는 PC 쪽 주소 설정(`~/.ssh/config` 등)은 자동으로 바뀌지 않는다. 새 주소는 `status`에 표시된다.
- 공유기의 DHCP 예약(고정 배정)이 더 근본적인 해결책이다. 이 내용은 화면에서 계속 안내한다.
- 실기 검증은 DHCP를 쓰는 PC에서 해야 한다(T12 확장, M7 신규 설치 PC).
