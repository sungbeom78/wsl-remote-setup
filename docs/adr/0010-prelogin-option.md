# ADR 0010 — 로그인 전 접속을 설치 선택 기능으로 제공

- 상태: 채택 (사용자 결정, 2026-10-18)

## 맥락

2026-10-18 22:00 재시험에서 시험 작업(BootTrigger+S4U)으로 로그인 전 외부 LAN SSH 로그인이 성공했다(TEST_RESULTS 21:56~22:00). 이전 실패는 접속 도구의 주소 오기(`.221`) 때문이었다.

개발 지침상 1.0은 "로그인 후"가 기본이며, 무인 부팅은 자동으로 완료하지 않는다.

## 결정

1. 설치 질문 6번 "로그인하지 않아도 접속할 수 있게 할까요?"
   - 기본값은 **아니오**([y/N]).
   - 이미 켜 둔 PC에서 다시 실행하면 현재 상태(켜짐)를 기본값으로 보여 준다.
2. `autostart install --prelogin on|off`: 설치 마법사가 한 관리자 창에서 자동 실행과 함께 적용한다(추가 질문 없음).
3. 단독 명령: `autostart prelogin-on | prelogin-off`. 시험 때 쓰던 `boot-poc-create|remove`는 호환용으로 남긴다.
4. 작업 이름(`\WslRemoteSetup\BootAgent-<id8>`)과 방식은 시험과 같다.
   - 소유자 S4U, LeastPrivilege, 비밀번호를 저장하지 않는다.
   - G2에 있는 작업이 그대로 제품 기능이 된다.
5. `status`에 "로그인 전 접속: 켜짐/꺼짐"을 표시한다. 꺼짐은 정보일 뿐 종합 판정을 낮추지 않는다.
6. 끄기와 되돌리기(`autostart remove`)는 세션 0에 남은 에이전트까지 끝낸다. 끄기는 로그인 작업도 다시 시작한다.

## 제한

- S4U는 네트워크 자격 증명이 없다. 로그인 전 WSL에서는 Windows 네트워크 공유 접근이 제한될 수 있다(SSH에는 무관).
- 로그인 후에는 세션 0 에이전트가 계속 동작하고, 로그온 에이전트는 잠금 때문에 바로 끝난다. `status`는 최근 3분 점검 기록으로 실행 여부를 판단한다.
- Wi-Fi PC는 "모든 사용자" Wi-Fi 프로필이어야 로그인 전에 연결된다. G2는 연결됨을 확인했다. 개인 프로필이면 로그인 전 연결이 안 될 수 있다(NOT_TESTED).
- 신규 PC 설치(M7)에서 선택→적용 흐름은 NOT_TESTED.
